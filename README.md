# ProSMEFTion

ProSMEFTion projects a dimension-six SMEFT Lagrangian onto the operator basis generated by
[AutoEFT](https://gitlab.com/auto_eft/autoeft). A typical input is the one-loop matching output of
[BSUOLEA](https://arxiv.org/abs/2103.02487).

The program proceeds in these steps:

1. It rewrites the input operators in two-component SL(2,C) notation, with Weyl spinors and chiral field strengths.
2. It sorts the terms by field content.
3. It removes redundancies: duplicate terms, equations of motion, repeated fields, and integration-by-parts and
   Schouten identities, applied until all Lorentz Young tableaux are semistandard.
4. It projects the SU(2) and SU(3) structures onto AutoEFT's basis tensors.

The algebra runs in [FORM](https://www.nikhef.nl/~form/), and the group theory comes from AutoEFT (which builds on
[SageMath](https://www.sagemath.org/)).

## Requirements

- [FORM](https://github.com/form-dev/form) ≥ 4.3, with `form` on your `PATH`.
- Python 3.12 with SageMath 10.8 and AutoEFT 1.0.2. `environment.yml` installs both. Do not use SageMath 10.9:
  `Permutation.signature()` returns a Sage `Integer` there, and AutoEFT 1.0.2 then fails when it multiplies the
  sign with a Python `Fraction`.
- Optional, for `-t`: `pdflatex` with the LaTeX package `autobreak`.

FORM is driven through POSIX pipes, so ProSMEFTion runs on Linux and macOS.

## Installation

```bash
git clone git@github.com:jakoblinder/prosmeftion.git
cd prosmeftion
conda env create -f environment.yml
conda activate prosmeftion
```

Keep the environment activated for everything below: Sage needs the environment's `bin/` on `PATH` (for Singular).
`autoeft check` tests the installation.

If conda reports that `sagelib` needs `__osx >=11.0` on a recent macOS, your conda base is reporting the old
compatibility version `10.16`. Prefix the command with `CONDA_OVERRIDE_OSX=$(sw_vers -productVersion)`.

## AutoEFT basis

ProSMEFTion reads the AutoEFT basis of every mass dimension from 4 up to `-d` (default 6). The `BASIS` argument is the
model's output directory, which contains `<dim>/basis/`. Two bases are included, generated with AutoEFT 1.0.2 from
the model files in `models/`:

- `efts/ssm-eft`: SM fields without the gluon field strength. It is sufficient for all examples.
- `efts/sm-eft`: the full SM.

To regenerate a basis, run from the repository root:

```bash
for d in 4 5 6; do autoeft construct --overwrite models/ssm.yml $d; done
```

This takes about half a minute. The field names in the model must match the AutoEFT names in
`config/op_config.yml`: `H`, `Q`, `L`, `uC`, `dC`, `eC`, `BL`, `WL`, `GL`.

## Usage

```bash
python main.py LAGRANGIAN BASIS [-f {form,mathematica}] [-s SKIP] [-d DIM] [-t] [-l LEVEL]
```

| Argument | Meaning |
| --- | --- |
| `LAGRANGIAN` | File with the matched Lagrangian. |
| `BASIS` | AutoEFT basis directory, e.g. `efts/ssm-eft`. |
| `-f`, `--format` | Input syntax: `form` (default) or `mathematica`. All examples are `mathematica`. |
| `-s`, `--skip` | Number of header lines to skip in the input file (default 0). |
| `-d`, `--dimension` | Maximum mass dimension (default 6). |
| `-t`, `--tex` | Also write PDFs of the intermediate and final terms. |
| `-l`, `--log` | Console log level, from `DEBUG` to `CRITICAL` (default `INFO`). |

Examples:

```bash
python main.py 'Examples/BWHH+/BWHH+.m' efts/ssm-eft -f mathematica           # 2 terms, ~10 s
python main.py 'Examples/QDHH+Q+/QDHH+Q+.m' efts/ssm-eft -f mathematica       # 5 terms, ~10 s
python main.py BS/exampleOutputBS.m efts/ssm-eft -f mathematica -s 22         # 85 terms, ~2 min
```

The other inputs in `Examples/` (`ScalarToy/`, `4Higgs_*`, ...) are test cases from the thesis.
`BS/exampleOutputBS.m` is BSUOLEA output for the real-singlet extension of the SM from
[arXiv:2003.05936](https://arxiv.org/abs/2003.05936).

## Input format

The input is one Mathematica list `{...}`. It holds a sum of terms, and each term is built as follows:

- It starts with a coefficient, which must be written even when it is `1`.
- The fields and tensors are joined by the non-commutative product `**`.
- The term is divided by the matching power of the heavy mass `Ms`.

```mathematica
{((1)*F[{lor1,lor2}]**H[{gauge1}]**TT[{gaugeadj1},{gauge2,gauge1}]**V[{gaugeadj1},{lor1,lor2}]**conj[H][{gauge2}])/Ms^2}
```

Every object is written as `Name[{...},{...},...]`:

- Indices of the same type are grouped in braces, in the order `lor, spin, gauge, gaugeadj, colf, cola, flav`. These
  are the Lorentz, Dirac spinor, SU(2) fundamental and adjoint, SU(3) fundamental and adjoint, and flavour indices.
- An index is its type followed by digits or letters, e.g. `gauge5289`.
- All indices must be contracted.

| Symbol | Object |
| --- | --- |
| `H`, `conj[H]` | Higgs doublet |
| `l`, `q` | lepton and quark doublets (Dirac) |
| `e`, `u`, `b` | right-handed leptons, up and down quarks (Dirac) |
| `bar[psi]`, `C[psi]` | Dirac conjugate and charge conjugate of a fermion |
| `F`, `V`, `G` | U(1), SU(2), SU(3) field strengths |
| `cov[{lor}, field]` | covariant derivative |
| `gamma`, `sigma2lor` | Dirac matrices (Weyl representation) |
| `TT` | SU(2) and SU(3) generators |
| `su2eps`, `su3eps` | Levi-Civita tensors |
| `yu`, `yd`, `ye`, `conj[...]` | Yukawa matrices |

`config/op_config.yml` defines all symbols, their index structures and the couplings. The couplings defined there
are those of the real-singlet example. The couplings of other models have to be added there.

## Output

- `<input>_yBasis_<N>.h` in the repository root: the `N` projected terms in FORM syntax, one per line. Each term is a
  coefficient times AutoEFT basis tensors times fields in two-component notation.
- `projection.log` in the working directory: the full debug log.
- With `-t`: PDFs of the intermediate and final terms in the repository root.
- Intermediate files: FORM programs in `form_files/` (`form_files/general/` is regenerated on every run),
  `config/*.p` and `Latex/terms_all.tex`.

## Layout

```text
main.py              command-line entry point
prosmeftion/         conversion to SL(2,C) notation, EOM/IBP/Schouten reduction, SU(N) projection, FORM interface
config/              field, tensor, coupling and index definitions; logging
form_files/general/  FORM procedures
Latex/terms.tex      LaTeX wrapper for -t
models/, efts/       AutoEFT model files and the generated bases
Examples/, BS/       example inputs
notation/            notes on notation and conventions (LaTeX)
```

## Origin

ProSMEFTion was written by Jakob Linder in a master thesis at RWTH Aachen University, as an extension of AutoEFT. The
history in this repository is taken from the AutoEFT development repository, restricted to the author's commits.
The branch `thesis` holds the state at the end of the thesis (October 2022).
